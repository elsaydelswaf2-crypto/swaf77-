# Türkçe Akademi

منصة عربية مبسطة لبدء تعلم اللغة التركية. هذه أول نسخة ويب قابلة للتجربة، وتعمل مباشرة من المتصفح دون تثبيت أو اشتراك.

## تشغيل المشروع
افتح `index.html` في المتصفح، أو انشر محتويات المستودع باستخدام GitHub Pages.

## الموجود حاليًا
- واجهة عربية من اليمين إلى اليسار ومتجاوبة مع الهاتف.
- مفردات تركية أساسية مع ترجمة ونطق تقريبي.
- زر استماع يستخدم النطق التركي المتاح في جهاز المستخدم (قد يختلف توفر الصوت حسب الجهاز).
- اختبار قصير مع تصحيح ونتيجة فورية.

## الملفات
- `index.html`: الصفحة الرئيسية.
- `style.css`: التصميم.
- `app.js`: المفردات والاختبار والتفاعلات.

## ما لم يكتمل بعد
هذه نسخة تأسيسية وليست منهجًا معتمدًا أو تطبيقًا مكتملًا. يلزم إضافة بقية مستويات CEFR، ومراجعة لغوية متخصصة، وتسجيلات مدرسين أتراك حقيقية مرخصة، وحفظ تقدم المستخدم ومزامنته.
